# Telegram

1. **01_Аватары_ФИНАЛ_В** — единственный выбранный финал: исходный В «Графический знак». Для установки брать `png`, для редактирования — `svg`. ZIP и просмотр всех шести рядом.
2. **02_Эмодзи_24** — статичные кастомные эмодзи. `png_100` — основной формат загрузки; `webp_100` — альтернативные копии; `svg` — исходники. Инструкция и CSV привязок рядом. Пак ещё не опубликован.
3. **03_Баннер_закрепа_и_обои** — баннер приветственного/закреплённого поста и необязательные обои. Это не файл отдельной шапки профиля.
4. **04_Эмодзи_Дополнение_3** — три новых эмодзи «Ссылка», «GitHub», «Информация» в том же стиле В. Вместе с прежними 24 — всего 27; исходный комплект не изменён. ZIP содержит только новые значки.
5. **90_Архив_аватаров** — все предыдущие концепты и сравнения. Даже если внутри имя содержит «итоговый», это уже архивная версия.
