# Telegram

1. **01_Аватары_ФИНАЛ_В** — единственный выбранный финал: исходный В «Графический знак». Для установки брать `png`, для редактирования — `svg`. ZIP и просмотр всех шести рядом.
2. **02_Эмодзи_27** — единый набор статичных кастомных эмодзи: прежние 24 (побайтово неизменны) плюс «Ссылка», «GitHub», «Информация». `png_100` — основной формат загрузки; `webp_100` — альтернативные копии; `svg` — исходники. Текущий комплект — `MOKO_27_эмодзи_v02.zip`, прежний v01 сохранён как история. Пак ещё не опубликован.
3. **03_Баннер_закрепа_и_обои** — баннер приветственного/закреплённого поста и необязательные обои. Это не файл отдельной шапки профиля.
4. **05_Аватар_MOKO_Telegraph** — новая иконка паблика MOKO Telegraph: телеграфный ключ и азбука Морзе, стиль В. PNG 1024 для установки, SVG для правок, превью с круглой обрезкой.
5. **90_Архив_аватаров** — все предыдущие концепты и сравнения. Даже если внутри имя содержит «итоговый», это уже архивная версия.
