PNG: 1024 × 1024, основной формат для установки. Они получены без потерь из того же рендера, который дал выбранные JPG-превью варианта В; соответствие исходному рендеру проверено.
SVG: векторная версия с масками яркости и текстом в контурах; установка шрифтов не требуется. При импорте в редакторы проверяйте поддержку масок. Сглаживание краёв может немного отличаться от PNG.
HTML: автономная презентация. JPG: общий обзор, не файл для установки.

Для Telegram устанавливайте квадратный PNG целиком, без дополнительного приближения. Круг формируется при отображении. Символ гарнитуры обозначает связь с командой, а не наличие звонков.

В комплекте нет альтернатив. Остальные концепты перенесены в архивные сравнения. На площадках ничего не опубликовано.
