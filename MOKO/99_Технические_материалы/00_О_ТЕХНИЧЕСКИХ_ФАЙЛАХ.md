# Технические материалы

- **Рабочий_код_и_данные** — исторические генераторы, JSON, промежуточные ресурсы, данные роликов, логи и проверки; сохранена прежняя внутренняя иерархия.
- **Организация** — карта переноса всех 732 файлов, SHA-256, отчёт, служебный скрипт сортировки и восстановление временного рабочего дерева для следующих правок.

Для установки оформления этот раздел не нужен. Исторические скрипты содержат старые пути — используйте описанный в папке `Организация` способ восстановления рабочей копии.
