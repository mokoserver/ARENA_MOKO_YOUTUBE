# ОПЫТ агента MOKO Telegram

Живая база уроков. Читать перед работой, дополнять после.

## Вкус владельца
- Крупные залитые узнаваемые знаки; тонкие линии и мелкие детали = брак.
- Разные цвета рубрик — хорошо; «всё чёрно-красное» — плохо.
- Строгий корпоративный = плоский, без кругов/обводок, но разноцветный по разделам.
- Хочет видеть превью до публикации; варианты сравнивает вживую в Telegram.
- Работает с телефона: файлы и ссылки давать готовыми, структуру держать плоской и понятной.

## Решения, которые нельзя ломать
- Финал аватаров Telegram — только исходный В «Графический знак» (не В1/В2).
- Johnny Respect — в семье MOKO.
- Утверждённые наборы не переписывать; новые версии — новыми файлами (v01/v02/v03, ZIP как история).
- Архивные папки — резерв; не удалять из GitHub без прямого запроса.

## Технические грабли
- Bot API: createNewStickerSet custom_emoji работает; без START владельца боту — «user not found».
- Эмодзи для GitHub в Unicode нет → привязка 💻.
- PNG/WebP 100×100 RGBA, прозрачный угол; либо PNG, либо WebP в пак, не оба.
- openpyxl delete_rows оставляет фантомные строки с гиперссылками → лист пересобирать из карты заново.
- В песочнице между сессиями исчезают pip/apt/.cache: зависимости ставить заново; секреты не писать в файлы проекта.
- Галереи проверять браузером на 390 px: без прокрутки и js-ошибок; картинки все loaded.
- cairosvg: текст в SVG недопустим (только контуры/фигуры) — иначе разный рендер.
