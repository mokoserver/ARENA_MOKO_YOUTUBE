# Организация файлов и дальнейшие правки

## Что сделано

Все 732 существовавших файла из прежних `moko/` и `uploads/` перенесены в тематические папки `MOKO/`. Каждый исходный файл проверен по SHA-256 после переноса. Оригинальные изображения, документы и ZIP не редактировались. Общие аватары дополнительно скопированы в YouTube и VK — 8 небольших файлов для удобства.

- `Карта_переноса.json` — полная адресная карта с размером, SHA-256, площадкой, назначением и статусом.
- `Старые_и_новые_пути.csv` — упрощённый указатель прежних адресов.
- `Отчёт_проверки.json` — результат контроля переноса.
- `Дополнительные_копии.json` — 8 удобных копий аватаров.
- `organize.py` — скрипт этой сортировки.
- `restore_workspace.py` — проверка сохранности и восстановление временной рабочей копии.

18.09.2026 по запросу пользователя папка старых итераций YouTube `01_YouTube/90_Архив_этапов` (55 МБ) удалена из воркспейса. Строки карты для этих файлов помечены `removed`, проверка и восстановление их пропускают. GitHub-репозиторий не очищался: он хранит полный набор, включая архив, как резервную копию. При следующих пушах не возвращайте архив в воркспейс и не удаляйте его из репозитория без нового запроса.

## Важное про старые скрипты

В `Рабочий_код_и_данные` сохранены исторические скрипты и JSON с их исходными путями. Они не переписывались при сортировке — это позволяет подтвердить побайтовую сохранность и не вносить скрытые изменения в старые материалы.

**Не запускайте исторические скрипты прямо из новых папок без подготовки путей.** Для дальнейших доработок предусмотрено восстановление прежней структуры в отдельной временной рабочей папке. В этой копии абсолютные пути адаптируются, а отсортированные материалы остаются нетронутыми.

### Проверить сохранность

Из `/home/user`:

```bash
python 'MOKO/99_Технические_материалы/Организация/restore_workspace.py' --check
```

### Восстановить временную рабочую копию

```bash
python 'MOKO/99_Технические_материалы/Организация/restore_workspace.py' --restore --hydrate-archived
```

По умолчанию создаётся `/home/user/.cache/MOKO_workbench/`, внутри — прежние `moko/` и `uploads/`. Временная папка не является выдаваемым комплектом и может не сохраняться между сессиями. Её можно заново создать из карты.

Для другой пустой папки:

```bash
python 'MOKO/99_Технические_материалы/Организация/restore_workspace.py' --restore --destination /home/user/.cache/MOKO_edit_02 --hydrate-archived
```

Флаг `--hydrate-archived` дополнительно восстанавливает часть старых PNG из сохранённых ZIP или SVG, если такие записи есть в предыдущих архивных манифестах.

Некоторые отвергнутые промежуточные растры были архивированы/удалены **ещё до этой сортировки**. В архивных сравнениях сохранены превью, а в технических материалах — записи и генераторы. Восстановление текущей карты не обещает вернуть любые исторические файлы, которых уже не было к моменту переноса. Перед запуском старых генераторов следует проверить их входы и заметки.

## Как передавать файлы пользователю

Для установки использовать тематические папки `01_YouTube`, `02_Telegram`, `03_GitHub`, `04_VK` и `05_Бренд_MOKO`, а не временную рабочую копию. Единственный финальный Telegram-аватарный стиль — исходный В. Старые сравнения и промежуточные «итоговые» наборы остаются в папках `90_Архив…`.

ZIP-наборы сохранены в исходном виде. Папки внутри ZIP могут называться иначе, чем новые внешние папки сортировки — это сделано намеренно, чтобы ранее выданные архивы остались неизменными.
