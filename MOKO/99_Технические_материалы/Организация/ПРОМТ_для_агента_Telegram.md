## 4. Загрузка и выгрузка эмодзи (техника)

- **Публикация**: скрипт `MOKO/99_Технические_материалы/Организация/publish_telegram_pack.py` — Bot API `createNewStickerSet` со `sticker_type=custom_emoji`, привязки из manifest.json, на выходе `t.me/addemoji/…`. Требует: токен бота, ID владельца, и чтобы владелец заранее нажал **START** этому боту (иначе «user not found»). Добавление в существующий набор — `addStickerToSet`.
- **Выгрузка (скачивание своих коллекций)**: Bot API `getStickerSet` по имени набора → у каждого стикера `file_id` → `getFile` → `https://api.telegram.org/file/bot<token>/<path>`; складывай в соответствующую папку `MOKO/02_Telegram/…` и обновляй каталог.
- Ручной путь (без бота): @Stickers → `/newemojipack`, файлы отправлять как документы без сжатия.
- Помни: использование кастомных эмодзи в чатах может требовать Telegram Premium; создание наборов — нет.

## 5. Как делать новые эмодзи

1. Уточни набор, стиль (В / тёмный / строгий) и разделы; предложи свои разделы по контексту, если владелец дал список.
2. Рисуй SVG 100×100: знак занимает почти весь круг/кадр; заливка вместо тонких линий; без текста внутри (контуром нельзя — мелкие надписи нечитаемы).
3. Сгенерируй PNG 100×100 (cairosvg 400→100 LANCZOS) + WebP lossless + SVG; проверь: размер 100×100, alpha (0,255), угол прозрачный, байт < 64000.
4. Собери галерею-HTML (автономная, data-URI, мобильная ширина без прокрутки) + превью-JPG со строками 22/28 px на тёмном и светлом.
5. Покажи владельцу превью ДО публикации; не меняй утверждённые наборы без запроса; старые версии храни как историю (ZIP v01/v02…).
6. Обнови каталог `MOKO/00_Каталог_файлов.xlsx` и указатель `MOKO/00_НАЧНИТЕ_ЗДЕСЬ.md`, запиши в ЛОГ и ОПЫТ, запушь.
