# MOKO — материалы по площадкам и задачам

Обложки, оформление, аватары, эмодзи, документы, архивы вариантов и технические исходники совместной работы. Все материалы собраны в папке **MOKO**.

## Начать здесь

- **[Главный указатель](MOKO/00_НАЧНИТЕ_ЗДЕСЬ.md)** — быстрые ссылки и описание комплектов.
- **[Каталог файлов Excel](MOKO/00_Каталог_файлов.xlsx)** — 669 материалов с фильтрами по площадке, теме, названию и формату; служебная навигация хранится отдельно.
- **[Дерево папок](MOKO/00_Дерево_папок.txt)** — структура разделов.

## Статусы и использование

- **Telegram: единственный финал аватаров — исходный В «Графический знак»**, не В1 и не В2. Ранние варианты находятся в папках `90_Архив…`.
- **YouTube: 18 обложек согласованы, 76 ожидают проверки.** Наличие файла в репозитории не означает его согласование.
- Эмодзи собраны в единый набор 27 (прежние 24 побайтово неизменны, добавлены «Ссылка», «GitHub», «Информация»). Добавлен аватар паблика MOKO Telegraph. Telegram-пак ещё не опубликован. Аватары и оформление на площадках автоматически не устанавливались.
- HTML-галереи скачайте и откройте в браузере: GitHub показывает их исходный код, а не интерактивную страницу. Для галерей с относительными ресурсами сохраняйте структуру папок; также доступны готовые ZIP-комплекты.
- Исторические скрипты содержат прежние рабочие пути. Перед запуском прочитайте [инструкцию восстановления рабочей копии](MOKO/99_Технические_материалы/Организация/README.md).

В первый коммит включены все 757 файлов организованной папки MOKO без изменения содержимого и этот указатель. Токены доступа и временные рабочие копии не включены.
